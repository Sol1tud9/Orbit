# Эксплуатация и публикация

## Один локальный сервер

`docker compose up --build -d` собирает React в Node-стадии, переносит статические файлы в Python-образ и запускает FastAPI непривилегированным пользователем. Порт по умолчанию доступен только на localhost:8000. `ORBITA_PORT` меняет внешний порт. База и артефакты находятся в томе `orbita-data`, каталог контейнера `/data`.

Проверки: `docker compose ps`, `docker compose logs --tail 100 app`, `/api/health`. Во время расчёта CPU используется дочерними процессами; API запускается строго с одним worker. Health проверяет доступность HTTP, а не правильность математической модели — для последней нужны тесты.

Для резервной копии остановить app и скопировать **весь** том, включая SQLite WAL и артефакты; затем снова запустить. Не копировать только основной файл SQLite при работающем сервисе. Не использовать `down -v`, если результаты нужно сохранить. После восстановления нужны также cookie пользователей для прежнего доступа к истории; экспортированные сценарии можно рассчитать заново в новом сеансе.

## Внешняя ссылка с HTTPS

Подготовлен дополнительный Compose с Caddy. Нужны Linux-сервер с Docker, домен с DNS на сервер и открытые 80/443. На сервере создать `.env` по `.env.example`, указать реальный `ORBITA_DOMAIN`, затем:

```sh
docker compose -f compose.yaml -f compose.public.yaml up --build -d
```

Caddy получает TLS-сертификат и проксирует приложение; public override включает Secure cookie. Проверить HTTPS в новом браузерном сеансе, импорт нового JSON, расчёт и экспорт. Перенос cookies с HTTP localhost не требуется. Пока сервер/домен не предоставлены, внешняя ссылка не создана и её доступность не подтверждена.

Сервис предназначен для ограниченной демонстрационной аудитории. Перед открытым неограниченным доступом нужны общие ограничения частоты запросов, политика удаления старых артефактов, наблюдение за диском и CPU. Текущие лимиты заданий и входа описаны в [архитектуре](ARCHITECTURE.md).

## Диагностика

- «Прерван»: сервер перезапустился до окончания задания; повторить расчёт, исходная ревизия сохранена.
- «Сценарий превышает ресурсный бюджет»: уменьшить объём или осознанно увеличить `ORBITA_MAX_WORK` после измерений.
- Пустая история в другом браузере: история привязана к HttpOnly cookie-сеансу.
- UI не открывается при запуске Python: сначала выполнить `npm ci` и `npm run build` в `web`, затем перезапустить API.
- E2E не запускает backend: активировать Python-окружение и освободить порт 8011.
