# Статус реализации

## Текущий пакет: этапы 0–2

- **0. Контракт:** изучены все материалы; зафиксированы математические правила, структурная валидация, схемы, контрольные результаты и SHA оригинала.
- **1. Независимое ядро:** произвольный допустимый сценарий проходит через CLI/API до маршрутов, метрик, интервалов, объяснений и обязательного экспорта. Контрольные и дополнительные проверки автоматизированы.
- **2. Рабочий веб-контур:** загрузка, фоновый запуск/отмена, карта и топология, выбор клиента/отсчёта, маршрут, причины, перерывы, история, повторный запуск, экспорт. Контейнер собран и локально запускается. Внешняя публикация требует согласованного сервера и домена; конфигурация HTTPS подготовлена.

Следующие этапы не объявляются выполненными наличием похожих элементов интерфейса. Сейчас параметры доступны для просмотра и изменения через загружаемый JSON; встроенного редактора и полноценного A/B ещё нет.

## Следующий пакет: этапы 3–5

| Этап | Результат | Критерий готовности |
|---|---|---|
| 3. Проектирование и A/B | Формы окружения/плоскостей/фаз, редактирование состава и отказов, ветки ревизий, diff, два результата и общий курсор | Изменение каждого предусмотренного поля, сохранение/загрузка без потерь; сравнение всех клиентов; несовместимые условия явно выявлены; результаты не устаревают незаметно |
| 4. Визуальная среда | Согласованные глобус/карта/граф, масштабирование timeline, таблица контактов, улучшенный инспектор и клавиатурная навигация | Правильные оси ECEF; читаемый маршрут до 18 рёбер; поиск худшего перерыва без подсказок; 1280×720, 1440×900 и fallback без WebGL |
| 5. Устойчивость | Альтернативные пути, N−1, контрфактическая проверка причин и рекомендации с численными доказательствами | Каждое улучшение подтверждено полным пересчётом; потери/выигрыши показаны по всем клиентам; отмена пакетного эксперимента; нет необоснованных выводов |

Этап 3 следует начать с отделения draft/revision/comparison state от координатора App и контракта сопоставимости, затем добавить формы. Расчётное ядро и эталон при этом менять не требуется.

## Финальные этапы

6. Дополнительный эффект: согласованное воспроизведение A/B, ограниченный автоподбор с воспроизводимым seed, Pareto-кандидаты. Не откладывать обязательные возможности ради этих функций.

7. Выпуск: нагрузка на целевой машине, внешняя ссылка, независимый чистый запуск, полный E2E редактирование → отказ → сравнение → вывод → экспорт, демонстрация до 5 минут. Обязательна проверка новым JSON жюри.
